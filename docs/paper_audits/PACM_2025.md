# PACM on the fixed IFC pool

This implementation adapts Algorithm 1 of [Cheng et al. (2025)](https://doi.org/10.1109/TCC.2025.3612584). Its source is algorithms/pacm.py. The benchmark supplies a fixed heterogeneous pool and charges the execution of each task on its selected slot. The published model can provision and upgrade VM instances and bills rental intervals. These assumptions change the mapping decision.

## Reproduction decisions

- Use the benchmark deadline and insertion evaluator. Measure policy runtime separately from the workflow makespan. Costs exclude communication charges, and transfer times use the frozen routes.
- For equations 11–13, use fastest-slot task time and theta 1.5. Follow the displayed equation 13 (current task computation time divided by edge transfer time) where the surrounding prose describes the ratio in the opposite direction. Draw once per nonzero-delay edge, in the pinned graph's reverse topological traversal. Run seeds 0–9 for every instance as for ProLiS.
- For pre-placement transfer estimates, average the IFC route times over ordered distinct slots. For equations 14–17, average processing times over all slots, compute both path lengths in exact scaled integer time and mark every task on a longest path. Multiple roots and sinks have implicit zero-time endpoints and transfers. Compute the real-task in-degree distribution without adding virtual edges.
- Equation 18 initializes each terminal task's latest finish to the common deadline. Equations 20–22 use population standard deviation, total real edges and task in-degree. Set the correction to zero on edgeless DAGs. Compute equation 22 in seconds and convert back to IFC microseconds. This convention matters because the printed equation adds a dimensionless degree term to numerical durations.
- For equations 23–24 interpret distance as transfer time accumulated from entry through the incoming edge of the current task. For tied longest prefixes use the largest accumulated transfer delay. In the critical branch the earliest-finish candidate is also the earliest-finish fallback, so a critical sub-deadline miss cannot change which slot wins.
- For a noncritical task use minimum incremental compute charge among slots meeting its sub-deadline, then earliest finish. If none qualifies, use earliest finish over all slots. Break remaining ties by lower charge and then slot ID. Returning a late schedule is a coverage miss. Do not relax the workflow deadline.
- For each case report both the minimum and the arithmetic mean of the costs over deadline-feasible seeds. Coverage counts unique instances with at least one feasible seed. Compare with archived v3 only on mutually feasible cases.

## Files and commands

The results/paper2/pacm directory contains raw per-attempt CSVs (XZ compression), seed coverage and paired comparisons including workload breakdowns. Its expansion folder also contains comparisons with the frozen 60-task CP-SAT references. All computed costs, makespans and policy times come from the benchmark harness. Runtime observations across separate executions have different machine and process conditions.

On the paper2-additional-heuristics branch, install requirements.txt, set cohort to expansion or unseen, and run:

```sh
algos=$(seq -s, -f 'pacm-s%g' 0 9)
python tools/data.py fetch --set "$cohort" --out "data/$cohort"
python tools/bench.py plan --set "$cohort" --algos "$algos" --shards 1 --reps 1 --workers 8
python tools/bench.py run --shard 0 --data "data/$cohort" --out "pacm-$cohort.csv"
python tools/pacm_report.py --cohort "$cohort" --pacm "pacm-$cohort.csv" \
  --archive previous-evidence.zip --dcds "results/paper2/dcds/$cohort.csv.gz" \
  --out "results/paper2/pacm/$cohort"
```

The archive is the journal-evidence artifact from [run 45041750746](https://github.com/alphanum545/ifc-scheduling-benchmark/actions/runs/45041750746), SHA-256 956fdca3c9011a127dd1d6dffabb4585ad46587d976239d0b89ddd21d470aaa7. The report checks the cohort and runs.csv digests, source identities, deadlines, validation fields and seed coverage before aggregation.
